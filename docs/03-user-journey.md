# User Journey

> MemoryClip User Journey
>
> From one memory to a complete documentary.

---

# Introduction

People do not think in terms of workflows.

They think in memories.

No one wakes up wanting to create a documentary.

Instead, they think:

> "I found my grandfather's old photographs."

> "I wish my children could know who she was."

> "I don't want these memories to disappear."

MemoryClip is designed around this emotional journey.

Technology should stay invisible.
